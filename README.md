# 航太加工製造客製化成本計算與報價 AI 助手

依使用者提供的影片重建四個深色工作頁面：圖面總覽、欄位校正、相似案例、報價明細。原始影片、PDF、PPTX 未修改。

## 啟動

雙擊 `start.bat`，使用瀏覽器開啟 http://127.0.0.1:8765/ 。保留服務視窗，Ctrl+C 停止。

啟動器優先使用本資料夾 `.venv`，其次使用本機 Codex 的 Python，最後尋找已安裝的 Python。其他電腦需要 Python 3.11 以上；首次執行會依 requirements.txt 安裝依賴。

亦可執行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

這是本機版，綁定 127.0.0.1，不需雲端帳號。勿將開發伺服器直接暴露於網際網路。

## 使用流程

1. 預設載入影片示範：垂直軸固定板。圖面由影片擷取，畫質受原始影片限制。
2. 點「上傳圖面」或拖曳 PDF、PNG、JPG、DXF（25 MB 以下）。PDF 目前渲染第 1 頁，會提示總頁數。上傳新檔會清除舊的加工欄位與成本輸入，避免把示範報價套用到新案件。
3. 「參數與 AI 設定」可填寫 OpenAI 相容的 Vision API URL 與視覺模型名稱，例如 LM Studio 的本機服務。按「開始分析」才會傳送圖面。API 金鑰不寫入資料庫，只存在當次瀏覽器記憶體；也可在伺服器環境變數 VISION_API_KEY 提供金鑰。
4. 未連接模型時，仍能人工填寫所有欄位與完成報價。系統不冒充已執行 AI。模型抽取結果未經核實，必須人工確認。
5. 在「欄位校正」修改右側欄位後按「套用修正」。攻牙、主尺寸等文字為註記，不自動推斷工時或重量；實際估價數字於「報價明細」設定。
6. 「報價明細」可調整數量、工時、材料重量、孔數、表面面積、加價、稅率、風險係數。改完按「套用參數並重新計算」。人工覆寫單價留空即恢復建議價。
7. 「儲存案例」或「確認寫回知識庫」會寫入本機 SQLite。確認報價會記錄已確認狀態。可从左側「已儲存案例」重新載入。
8. 「匯出 PDF / 列印」開啟瀏覽器列印，選擇「另存為 PDF」。另提供 UTF-8 BOM CSV 下載，方便 Excel 使用。

## 報價算法與來源

- **影片示範工時計價**：材料 85 + CNC 2100 + 去毛邊 20 + 鑽孔 120 + 攻牙 60 + 表面 155 + 設定 342 = 2882；風險 3.4% 取整為 98，單件成本 2980。成本加價 15% 得未稅單價 3427；數量 1、稅率 5% 時稅額 171、總額 3598。部分未在影片顯示完整的成本拆分是為重現總額而配置的可編輯範例，不代表原系統實際算法。
- **PDF 基準模式**：依提供的兩份掃描 PDF 人工核對，支援銑平面、鑽孔、攻牙、精搪孔費率；原始 PDF 可從頁面開啟。厚度小於 5 mm 用長 × 寬 × 0.005，否則 0.006；恰為 5 mm 原文未定義，介面提示人工確認。Ra 6.3 / 3.2 / 1.6 分別加 20% / 50% / 80%。
- 鑽孔直徑 ≤10 / ≤20 / ≤30 mm 基準 10 / 15 / 20 元，深度超過 25 mm 每 mm 加 0.5 元。攻牙 M≤10 / M12–18 / M20–30 基準 15 / 18 / 22 元，深度超過 20 mm 每 mm 加 0.5 元；細牙 / PT 每孔加 3 元。PDF 未定義範圍會要求人工處理。
- 精搪孔直徑 30–50 / >50–100 mm 基準 150 / 200 元，超過 30 mm 深度每 mm 加 2%，再乘幾何公差加成。公差 0.1–0.05 / <0.05–0.03 / <0.03–0.02 / <0.02–0.01 mm 分別加 20% / 40% / 50% / 70%。區間共用邊界採較低級距，原文未定義處不外推。
- 沉頭孔原始表有區間重疊，尚未自動計入；可在去毛邊等人工費用中調整並記錄備註。
- PDF 費率適用材質基準由原文保留，不聲稱為目前市場行情。
- 設定費按批次數量平均攤提。各單件成本採四捨五入整元；單件報價 × 數量後計稅。加價率是成本加成，不是營收毛利率。
- **參考案例**：簡報第 20 頁的 11 件零件與價格原值收錄；未提供完整規格，不杜撰相似度。簡報的垂直軸固定板 660 與影片的 2980 分開標示。
- **相似案例檢索**：僅對本機已儲存案例進行結構化特徵比對，材質 25%、品名 20%、長寬厚 35%、孔數 10%、複雜度 10%。沒有內建向量資料庫或完整語意 RAG。
- **DXF**：ezdxf 解析並渲染，統計實體、圓形、曲線、多段線頂點，依飽和函數加權產生 0–10 啟發式複雜度。這不是簡報中未公開權重的完整拓撲/分形算法。圓形實體不能直接當作加工孔數；DXF 尺寸單位與零件包絡需人工確認。

## 檔案結構

`app.py` 為 Flask 本機後端；`static/` 為前端與參考素材；`data/quotes.sqlite3` 保存案例；`uploads/` 保存上傳檔案與預覽。備份時請一起複製資料庫和 uploads，勿只複製前端。

系統沒有自動向外發布、發送報價或接入 ERP；確認報價只在本機留存。模型端點必須由使用者提供，未以實際模型驗證辨識品質。
